# 归档与特殊内容

## 本地归档的验收

备份盘必须真实挂载、可写、有足够空间。用用户指定位置；没指定且存在多个磁盘时先确认目标，不猜磁盘名称。创建专用目录，避免覆盖已有文件。同名附件加稳定序号或资源标识区分，保存原名映射。

保留原始读取响应、正文、目录层级、资源原件、批注、下载清单、校验报告及云端链接。离线 HTML 入口只使用经过转义的文字和本地相对链接，不嵌入原文脚本；所有附件和导航链接应可从备份盘打开。链接到云端视频不算离线备份。

目标硬盘重新计算哈希，不把网络下载成功直接当作硬盘写入成功。`backup_manifest.py` 可核验目录的完整文件集合；它证明备份文件自建立清单后未变化，不能证明云端资源是否已全部下载。两种证明都需要。

去重可在全部文件已验证后按实际哈希进行，同时保留每条记录的完整对应关系。不能仅因文件同名、相似画面或标题相同就删掉一个版本。缩小视频尺寸、转码、裁切、降低画质需要额外授权，默认保留原始文件。

## Base 与素材库

获取所有表、字段、视图、记录和全部分页，保存列类型、记录顺序、关联记录、公式及附件字段。下载每个附件，核对引用次数和唯一文件数；多个记录共用一个附件不是缺失。把每条记录的文字和附件关系写进离线索引。

只拿到第一页、只导出 CSV、只抓可见视图或只下载附件都不能称为完整素材库归档。链接字段若指向外部素材且任务要求离线可用，需要在授权内获取原件；无权访问就记录阻塞。

## 嵌入表格和画板

表格不能只比文字：核对全部工作表、维度、合并单元格、公式、原始值、格式、列宽及嵌入图片；颜色仅在确认语义等价时规范化比较。副本引用原表和创建独立新表是不同保留策略，需要明确依赖关系。

画板保存可读预览和原始结构，按支持的导出能力验证；只下载封面不能替代原始可编辑内容。同步块、外链预览和无法解析的组件仍可能依赖旧原件，保留原件直到关系明确。

## 失败与空间释放

某一附件原本已损坏，也不能承诺“完整备份”。可记录缺失、尝试在用户授权的本地历史备份中找回；没有实际找回就保留相应云端原件并报告。

复制遇到空间满、超时或中断，先检查副本是否已经创建，再决定重试。只清理本次可追溯的失败副本。回收站、历史版本、组织用量刷新存在平台差异，应读取实际状态；不自动永久删除或清空回收站来凑空间收益。
