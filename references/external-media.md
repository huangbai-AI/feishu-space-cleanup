# 视频外置与链接替换

用于用户明确要求把文档中的视频换成在线链接。普通空间整理不自动授权公开文件、开通付费存储或上传第三方平台。

## 先保留原片

保存完整原文、全部素材、原位置、文件名、大小、校验值、批注及子页面关系。先完成 archive.md 的硬盘核验，再处理视频块。历史版本占用可能在删除视频块后继续存在，仍需创建原生副本、核验并回收旧件。

## 选择链接

- 已有小红书、抖音、Instagram 等原帖时，逐条确认帖子可访问且对应同一段视频；不能把相关视频或同主题成片当作全部原始素材的替代。公开视频仍可能经过平台转码，原片留在本地备份中。
- 没有合适原帖时，使用用户批准的在线存储。确认可公开范围、费用、访问和下载方式；沿用当前用户明确批准的选择，不把别人的 GitHub 仓库、网盘或授权当作默认目的地。
- 用户允许公开原片时，只上传获准的视频及必要校验清单。文档全文、批注、协作者、账号信息、本地绝对路径和原文档标识不随视频公开。可用内容校验值命名，并把原文件名对应关系保留在私有备份。
- 文档内保存稳定入口，不能使用会过期的临时预览或签名地址冒充长期下载链接。

## 核验线上副本

新上传的原片需在预期访问条件下完整下载，核对大小和 SHA-256；公开原片用未登录条件验证。只返回成功状态、只读文件头或能看到播放封面都不足以证明原片可恢复。上传超时先查询是否已存在，避免重复上传。

逐一记录原视频块、素材标识、目标链接、访问条件和验证结果。一个原片多处引用可以共用链接，但必须保留每处引用的映射。

## 替换与回收

精确替换视频块，保留相邻文字、标题、表格和排版，不整篇重建。复读后与“原文仅按计划替换视频块”的预期内容比较，再原生复制；对照换链接后的完整原件核验副本正文及全部剩余附件。

按 verify.md 和 links-permissions.md 核对子页、批注存档、目录、协作者和链接。最后重新读取原件与副本，确认没有新增编辑或附件，再回收准确旧件。原件尚有未迁移子页或不能可靠映射的引用时，保留原件。

在保留文档中添加简短说明：原片备份位置、离线索引、恢复方法、在线链接的使用方式。原生副本没有保留评论线程时，明确批注存档位置，不称为完整线程迁移。

## 交付

分别报告替换视频位置数、不同原片数、沿用原帖数、回收旧件数和保留项。附当前在线入口与本地恢复索引。重新读取同一口径的容量；区分个人与组织、云文档与聊天及会议，说明统计延迟，不能用视频字节合计代替后台净释放量。
