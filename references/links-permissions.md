# 链接与权限

## 映射与修复

原件替换会改变文档标识。保存：原 URL、Wiki 节点、底层文档、新 URL、新底层文档以及能够准确定位的块锚点对应关系。

检查用户指定范围内的目录、汇总页、被处理文档间的互链和自引用，包括普通 `<a href>`、书签、`<cite type="doc">` 卡片、同步引用及嵌入资源。卡片不是纯文本链接；仅全文替换 URL 无法覆盖它。

先读取当前完整结构，再按准确块定位局部修改。需要创建或替换 XML 时先 parse；支持原生富文本元素修改时也须读取 schema、保持其他字段。一次替换同块所有目标，写后重新读取，确认除目标链接及必要块标识外，文字、样式、资源、表格行和顺序不变。

新文档中的自引用锚点应指向对应新块。不能把旧 `#block` 后缀原样拼到新文档就视为完成；无法建立可靠对应关系时保留原件或将该项列为待处理，与用户明确解决方式。

按资源标识查找，不能仅按同名标题替换，也不要因内容相关就换成另一篇。权限接口或元数据返回标题不代表文档仍可读：已删除文档有时仍返回元数据，需实际读取内容或打开页面验证。

只能证明检查范围内已修复的引用；平台没有完整反向链接枚举能力时，明确范围，尽量在删除前优先检查公开汇总入口。

## 权限的含义

按当前 `lark-drive` 权限指南读取：

```sh
lark-cli drive +permission-get-setting --token "$DOCUMENT_URL" --as user
```

- `anyone_readable`：互联网获得链接的人可阅读。
- `tenant_readable`：组织内获得链接的人可阅读，不满足互联网公开查看。
- `anyone_editable`：互联网可编辑，包含查看能力但范围更宽；不要称为“只读”。

同时检查对外访问是否允许。Wiki 读取优先使用节点权限；写入的字段限制以当次 schema 为准，不把 Wiki 明确不支持的字段发给它。

副本放回原位置不代表自动继承所有公开权限。对需保留公开访问的页面，在准确授权下修复并重新读取核验；不得擅自公开原本私有的商业合作资料。改公开权限前检查当前用户有无管理权限，只写需要改变的字段；不改协作者、所有者或下载规则来扩大范围。

接口读取失败可用用户授权的登录浏览器查看分享面板；等真实权限加载后再判断，初始“未开启”可能是占位状态。用户能登录读取，不证明互联网访客能读。分享面板、对外访问设置、密码、组织策略均要考虑。

没有管理权限就报告具体文档，不改身份碰运气，也不绕过组织策略。密码访问页面不能声称“获得链接就能查看”。不猜密码、不断言已删除，也不为修复权限自动创建公开副本。

## 浏览器收尾

优先用户指定浏览器。Ego Lite 使用前读取安装版本的指南，每个任务复用一个任务空间。任务结束前等待 `task.finish({ keep: [] })` 返回并核对关闭状态；若存在用户页面导致未关闭，不能擅自关闭用户页面，也不能宣称已全部关闭。不清登录信息或缓存。
